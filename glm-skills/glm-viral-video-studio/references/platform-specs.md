# Platform specs and post-publish optimization

## Specs
| | TikTok | YouTube Shorts | Long-form YouTube |
|---|---|---|---|
| Ratio | 9:16, 1080×1920 | 9:16, 1080×1920 | 16:9, 1920×1080 |
| Length to test first | 15–35s | 20–45s | 8–15 min |
| Text safe zone | avoid the bottom 15% (caption, buttons) and the right column (action buttons) | same | — |
| Thumbnail | pick a cover frame in the app; a custom 1080×1920 cover is possible | less important than for long-form | 1280×720, < 2MB, ≤ 4 words, readable at small size |
| Discovery | For You feed + in-app search → keywords in caption and in speech | Feed + keyword titles | Search + suggested → title & thumbnail drive CTR |

Shorter short-form videos usually have higher completion rates; only go longer when the content truly needs it.

## Cross-posting
Edit one 9:16 master without watermarks. Upload the original file separately to TikTok and Shorts (never upload a TikTok-watermarked video to YouTube). Rewrite title/caption per platform: YouTube leans on search keywords, TikTok on curiosity + hashtags.

## Caption templates
- TikTok: 1 hook line + 1 value line + a comment-bait question + 3–5 hashtags (1–2 broad, 2–3 niche from Creative Center).
- YouTube: title ≤ 60 characters with the main keyword; first 2 description lines contain the keyword + promise; pin a comment that asks a question.

## After publishing (48 hours)
1. YouTube Studio → Test & Compare: upload 3 thumbnails, 3 titles, or combinations; YouTube picks the winner by watch-time share, not CTR alone. Thumbnails must be ≥ 720p, otherwise the whole test is downscaled. Don't change anything else while the test runs.
2. Read the retention curve:
   - Sharp drop at 0–3s → broken hook: redo the hook, keep the body.
   - Drop in the middle → slow pace or off-topic: cut, add a visual change every 3–5s.
   - Good retention but few views → packaging (title/thumbnail/caption) or low-demand topic.
   - Industry reference: keeping ≥ ~75% of viewers past second 3 is good (a creator-published benchmark, not an official platform number).
3. Log it: topic, hook type, length, 3s retention %, 48h views. Read this log first in the next analysis.
