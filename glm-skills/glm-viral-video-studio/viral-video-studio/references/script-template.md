# Script template

## 0–3 second hook — 8 widely used types
Every script offers 3 hook options of 3 different types:
1. **Result first**: show the end result in the first second ("This is the $2,000 I made from...")
2. **Specific pain**: name exactly the problem the viewer has
3. **Counterintuitive**: "Stop saving money if you want to get rich"
4. **Open loop**: ask a question only answered by watching to the end
5. **Specific number**: "3 mistakes that make 90%..." (only numbers with a source)
6. **Warning**: "Don't buy X before watching this"
7. **Strange visual**: the first frame forces the brain to stop and figure it out
8. **Dialogue / POV**: role-play a familiar situation

Rules: on-screen text appears on the very first frame; no greetings, no channel intro, no logo at the start; the hook must match the real content.

## Short video structure (15–60 seconds)
| Part | Time | Job |
|---|---|---|
| Hook | 0–3s | Stop the scroll |
| Context | 3–8s | Why this matters to the viewer |
| Body | 8s – (end −5s) | 3 points/steps; a visual/text/angle change every 3–5 seconds |
| Payoff/twist | last 5s −2s | Close the open loop |
| CTA + loop | last 2s | Short CTA; the last line flows into the first line to encourage rewatching |

## Long-form YouTube structure (8–15 minutes)
Hook 0–30s (promise + proof) → content roadmap → 3–5 chapters, each opening a small loop → a "re-hook" every 60–90s → recap + next-video recommendation (end screen).
